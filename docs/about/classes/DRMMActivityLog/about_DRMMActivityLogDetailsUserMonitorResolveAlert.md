# about_DRMMActivityLogDetailsUserMonitorResolveAlert

## SHORT DESCRIPTION

Represents an activity log of entity USER, category monitor, and action resolve

## LONG DESCRIPTION

The DRMMActivityLogDetailsUserMonitorResolveAlert class models the details of an alert resolution activity log entry. It inherits the 12 common USER monitor properties from DRMMActivityLogDetailsUserMonitor (10 entity-level plus DataIsDeviceMonitor and DataMonitorId) and adds one property: DataAlertUidList, which contains the list of alert UIDs that were resolved.

This class inherits from [DRMMActivityLogDetailsUserMonitor](./about_DRMMActivityLogDetailsUserMonitor.md).

## PROPERTIES

The DRMMActivityLogDetailsUserMonitorResolveAlert class exposes the following properties:

| Property | Type | Description |
|----------|------|-------------|
| DataAlertUidList | string | The list of alert UIDs that were resolved. |

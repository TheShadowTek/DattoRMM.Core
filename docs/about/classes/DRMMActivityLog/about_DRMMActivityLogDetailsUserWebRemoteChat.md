# about_DRMMActivityLogDetailsUserWebRemoteChat

## SHORT DESCRIPTION

Base class for USER web

## LONG DESCRIPTION

The DRMMActivityLogDetailsUserWebRemoteChat class serves as a base class for USER entity web

This class inherits from [DRMMActivityLogEntityUser](./about_DRMMActivityLogEntityUser.md).

## PROPERTIES

The DRMMActivityLogDetailsUserWebRemoteChat class exposes the following properties:

| Property | Type | Description |
|----------|------|-------------|
| DataDetails    | string | Additional detail about the web remote chat session. |
| DataDeviceId   | string | The identifier of the device the web remote chat session was performed on. |
| DataDeviceName | string | The display name of the device the web remote chat session was performed on. |
| DataDeviceUid  | string | The unique identifier (UID) of the device the web remote chat session was performed on. |
| DataStart      | string | The start time or timestamp of the web remote chat session. |

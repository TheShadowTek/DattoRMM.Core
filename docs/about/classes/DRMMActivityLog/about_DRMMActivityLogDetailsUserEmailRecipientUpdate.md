# about_DRMMActivityLogDetailsUserEmailRecipientUpdate

## SHORT DESCRIPTION

Represents an activity log of entity USER, category email

## LONG DESCRIPTION

The DRMMActivityLogDetailsUserEmailRecipientUpdate class models the details of an email recipient update activity log entry. It inherits the 10 common USER entity properties from DRMMActivityLogDetailsUserEmailRecipient and adds two properties: DataContext, which describes the context of the update, and DataEmailRecipients, which contains the email recipient list after the change.

This class inherits from [DRMMActivityLogDetailsUserEmailRecipient](./about_DRMMActivityLogDetailsUserEmailRecipient.md).

## PROPERTIES

The DRMMActivityLogDetailsUserEmailRecipientUpdate class exposes the following properties:

| Property | Type | Description |
|----------|------|-------------|
| DataContext         | string | The context describing what email recipient configuration was updated. |
| DataEmailRecipients | string | The email recipient list after the update. |

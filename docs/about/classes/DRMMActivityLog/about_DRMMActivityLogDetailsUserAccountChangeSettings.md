# about_DRMMActivityLogDetailsUserAccountChangeSettings

## SHORT DESCRIPTION

Represents an activity log of entity USER, category account, and action change

## LONG DESCRIPTION

The DRMMActivityLogDetailsUserAccountChangeSettings class models the details of a user account settings change activity log entry. It inherits the 10 common USER entity properties from DRMMActivityLogDetailsUserAccount and adds the DataAccessControl property that describes the access control setting that was changed.

This class inherits from [DRMMActivityLogDetailsUserAccount](./about_DRMMActivityLogDetailsUserAccount.md).

## PROPERTIES

The DRMMActivityLogDetailsUserAccountChangeSettings class exposes the following properties:

| Property | Type | Description |
|----------|------|-------------|
| DataAccessControl | string | The access control setting that was changed during the account settings modification. |
